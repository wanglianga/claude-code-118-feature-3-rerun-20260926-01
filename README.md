# 城市工地围挡公益广告排期与验收系统

## 原始需求

> 设计城市工地围挡公益广告排期与验收页面，可使用 React、TypeScript 和 Zustand。广告公司或街道提交围挡画面时，页面记录工地位置、围挡长度、公益比例、商业画面、审批单位、安装时间、夜间照明、责任施工队和验收要求。审核人员在页面查看画面尺寸、文字、敏感内容、公益主题、品牌露出和道路视线影响；审核通过后，安装队按路段和围挡编号领取任务。现场安装时，需要上传安装前后照片、实际长度、缺口、遮挡交通标识和是否影响行人通行。若工地临时改围挡、画面被风吹破、公益时段未按比例展示、商户要求提前撤换、巡检发现脏污或验收长度与合同不符，页面要让广告公司、街道、施工队、巡检员、商户和财务围绕同一排期处理。验收完成后，页面生成可结算面积、扣款、整改和后续巡检计划。页面还要适配街道公益宣传、商业广告、工地安全提示和临时围挡改造的不同审批。巡检员看到的是现场安装和破损整改，广告公司看到的是可结算面积和扣款，街道看到的是公益比例和市容风险，三端状态需要同步。

## 技术栈

- **前端**：React 18 + TypeScript + Zustand + Ant Design 5 + React Router（Vite 构建）
- **后端**：Node.js 20 + Express + TypeScript，JSON 文件持久化（`/app/data/db.json` + 上传照片 `/app/data/uploads`，named volume 挂载）
- **部署**：多阶段 Dockerfile（非 root `node` 用户 + HEALTHCHECK），`docker compose` 一键启动，单容器同时提供 API 与前端页面

## 一键启动（验证方式 = 宿主 docker compose up）

```bash
cp .env.example .env        # 可选，修改端口/密钥；CC_PUBLISH_PORT 为宿主发布端口
docker compose up -d        # 构建并启动
docker compose ps           # 等待 STATUS 显示 (healthy)
docker compose port app 3000   # 查看实际映射的宿主端口（如 0.0.0.0:3218）
```

浏览器访问 `http://localhost:<CC_PUBLISH_PORT>/`（本任务环境为 `http://localhost:3218/`）。

- 仅应用端口发布到宿主（`${CC_PUBLISH_PORT}:3000`）；数据经 named volume `app-data` 持久化，无其他依赖服务。
- 首次启动自动写入种子数据（6 个不同状态的排期单、23 个安装任务、4 件异常工单、1 张待结算验收单、巡检计划）。
- 停止：`docker compose down`；清空数据重来：`docker compose down -v`。

## 业务闭环（建议演示路径）

1. **提交**（`ad001`/`street01` → 提交画面）：记录工地位置、围挡长度、公益比例、商业画面、审批单位、安装时间、夜间照明、责任施工队、验收要求；四类排期（街道公益宣传/商业广告/工地安全提示/临时围挡改造）适配不同审批单位与比例规则。
2. **审核**（`reviewer` → 审核中心）：逐项核查画面尺寸、文字、敏感内容、公益主题、品牌露出、道路视线影响；通过后**按路段+围挡编号自动生成安装任务**。
3. **安装**（`team01` → 安装任务）：领取任务，上报安装前/后照片、实际长度、缺口、遮挡交通标识、是否影响行人通行；全部上报后进入待验收。
4. **验收**（`reviewer`/`street01` → 验收中心）：确认验收长度，自动生成**可结算面积**（验收长度×高度，按公益比例拆分）、**扣款**（工单核扣 + 长度不符 1.2 倍违约扣款并自动开工单）、**整改项**、**后续巡检计划**。
5. **结算**（`finance` → 结算中心）：确认结算，排期单归档「已结算」。
6. **巡检**（`inspector` → 巡检中心）：执行验收生成的巡检计划；发现脏污/破损/公益比例异常时**自动生成异常工单**。
7. **异常工单**（六方协同）：工地临时改围挡、画面被风吹破、公益时段未按比例展示、商户提前撤换、巡检脏污、验收长度不符六类工单，按「发起→处理→结果→关闭」流转，财务核定扣款，整改项随工单关闭联动。

**三端同步**：所有状态存于同一后端，前端每 15 秒自动轮询同步（亦可点「同步」按钮）——巡检员看现场安装与破损整改、广告公司看可结算面积与扣款、街道看公益比例与市容风险，数据同源一致。
